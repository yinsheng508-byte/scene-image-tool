# 历史归档索引

`docs/archive/` 只保存历史资料，不作为当前开发事实来源。当前事实以 `docs/current/` 和 `docs/architecture/` 为准。

## 分类

| 目录 | 内容 | 数量 | 使用方式 |
|---|---:|---:|---|
| `legacy-plans/` | 历史需求、方案、任务卡、改造规划 | 41 | 需要背景时查阅，不能直接当作当前状态 |
| `reports/` | 历史烟测、回归、实施报告、发布记录 | 9 | 查验历史验证结果和环境限制 |
| `reference/` | 用户说明、接口说明、许可证、回滚说明、历史单页工具 | 7 | 作为参考资料，涉及接口或许可时需重新核对 |

## 使用规则

- 新需求和当前任务不要写入归档目录，应写入 `docs/current/`。
- 新模块、能力、组件、闸口和禁区不要写入归档目录，应写入 `docs/architecture/`。
- 从归档文档恢复任务前，必须重新核对 `code/desktop/` 当前实现。
