# PPT Stitcher Pro v1.0 - 产品需求文档 (V3)

> **版本**: V3 (多标签页模板方案)
> **更新日期**: 2026-01-23
> **产品类型**: 桌面端应用 (Windows / macOS)
> **核心功能**: PPT导出图批量自动化排版与合成
> **目标用户**: 小红书运营、自媒体创作者、电商运营
> **技术栈**: Electron + 原生 JavaScript + Canvas 2D + Sharp
> **开发状态**: 需求规划中

---

## 一、产品概述

### 1.1 背景与痛点

用户经常需要将PPT导出的多张图片，按照特定版式（如4格拼图、长图拼接）合成到精美的底图上，用于小红书等社交平台发布。目前手动PS或使用手机App效率低下，无法处理批量任务。

### 1.2 核心价值

**「定义一次模板，批量无限生成」**

用户只需在底图上画好坑位，设置简单的循环规则，软件即可自动将文件夹内的所有图片按顺序填入，生成高分辨率成品。

#### 2.4.5 预计生成数量计算

**单一文件夹循环**：
```
每轮消耗坑位数 = 拼图1坑位数 + 拼图2坑位数 + ...
完整轮数 = floor(图片总数 / 每轮消耗坑位数)
剩余图片 = 图片总数 % 每轮消耗坑位数
剩余需要拼图数 = 按拼图顺序依次扣减坑位数，直到剩余图片 <= 0
预计生成数量 = 完整轮数 × 拼图数量 + (剩余图片 > 0 ? 剩余需要拼图数 : 0)

示例：拼图1有4坑，拼图2有2坑，共15张图
每轮消耗 = 4 + 2 = 6
完整轮数 = floor(15 / 6) = 2 轮 → 生成 4 张
剩余图片 = 15 - 12 = 3 张 → 还需 1 张拼图1
预计生成 = 2×2 + 1 = 5 张
```

**封面 + 内页循环**：
```
封面消耗 = 拼图1坑位数
内页每轮消耗 = 拼图2坑位数 + 拼图3坑位数 + ...
若 图片总数 <= 封面消耗，则预计生成数量 = 1
否则：
剩余图片 = 图片总数 - 封面消耗
完整轮数 = floor(剩余图片 / 内页每轮消耗)
内页剩余图片 = 剩余图片 % 内页每轮消耗
内页额外拼图数 = 按拼图2开始依次扣减坑位数，直到内页剩余图片 <= 0
预计生成数量 = 1 + 完整轮数 × 内页拼图数量 + (内页剩余图片 > 0 ? 内页额外拼图数 : 0)

示例：拼图1有4坑，拼图2有2坑，拼图3有3坑，共15张图
封面消耗 = 4，剩余 = 11
内页每轮 = 2 + 3 = 5
完整轮数 = floor(11 / 5) = 2 轮 → 生成 4 张
剩余 = 11 - 10 = 1 张 → 还需 1 张拼图2
预计生成 = 1 + 4 + 1 = 6 张
```

## 三、核心功能详细需求

### 3.1 背景图（画布）

| 规则 | 说明 |
|------|------|
| 画布尺寸 | 有背景图时跟随背景图尺寸；透明背景时使用手动尺寸 |
| 更换背景图 | 画布尺寸跟随变化，已有坑位**按比例缩放**适配新尺寸 |
| 透明背景 | 开启后背景不参与导出，输出 PNG 透明背景 |
| 无背景图 | 透明背景关闭时：预览区提示「请先上传背景图」并禁用生成 |
| 输出尺寸 | 输出图片尺寸 = 画布尺寸 |

#### 3.1.1 更换背景图时的坑位缩放规则

当新背景图与旧背景图尺寸/比例不同时：

```
缩放比例 = min(新宽度/旧宽度, 新高度/旧高度)

所有坑位的 X, Y, W, H 都乘以该缩放比例
```

**规则说明**：
- **按较小比例缩放**：保证坑位不会超出画布边界
- **保持坑位形状**：宽高等比缩放，不会变形
- **保持相对位置**：坑位在画布中的相对位置不变

**示例**：
```
旧背景: 1080 × 1440 (3:4)
新背景: 1920 × 1080 (16:9)

缩放比例 = min(1920/1080, 1080/1440) = min(1.78, 0.75) = 0.75

原坑位: x=100, y=200, w=400, h=400
新坑位: x=75,  y=150, w=300, h=300
```

### 3.2 坑位操作

#### 3.2.1 基础操作

| 操作 | 方式 |
|------|------|
| **创建** | 点击「添加坑位」按钮 → 画布中央出现 200×200 的新坑位 |
| **选择** | 单击选中 / Ctrl+单击多选 |
| **移动** | 拖拽坑位 |
| **缩放** | 拖拽 8 个控制点 |
| **复制** | Ctrl+C → Ctrl+V（粘贴位置：原坑位右下方偏移 20px） |
| **删除** | Delete 键 或 点击删除按钮 |

> **v1.1 规划**：支持框选多个坑位

#### 3.2.2 坑位序号

- 位置：坑位左上角，小圆圈样式 ①②③④...
- 顺序规则：按绘制/创建先后顺序（先创建的序号小）
- **不可手动调整**：如需改变顺序，只能删掉重新创建


- **无最小尺寸限制**，用户自行负责

### 3.3 样式配置

坑位样式支持以下独立配置项，可自由组合：

| 配置项 | 类型 | 范围/选项 | 说明 |
|--------|------|-----------|------|
| **圆角** | 数值输入 | 0 ~ 100 px | 0 为直角，数值越大圆角越大 |
| **边框粗细** | 数值输入 | 0 ~ 20 px | 0 为无边框 |
| **边框颜色** | 颜色选择器 | 任意颜色 | 默认白色 #FFFFFF |
| **阴影** | 勾选框 | ☐ / ☑ | 是否显示投影阴影 |

**样式面板示意**：
```
┌───────────────────────────────────────────────────────┐
│ 圆角: [20] px   边框: [2] px [■ #FFFFFF]   ☑ 阴影   │
└───────────────────────────────────────────────────────┘
```

**样式设置规则**：
- 每个坑位独立保存样式配置
- 新建坑位默认：圆角 0，边框 0，边框颜色白色，无阴影
- 多选坑位时，可批量修改样式（应用到所有选中坑位）

#### 3.3.1 边框描边方式

边框采用**外描边**方式：

```
外描边示意：
┌─────────────────────┐
│ ┌─────────────────┐ │  ← 边框在坑位外侧
│ │                 │ │

└─────────────────────┘
      ↑ 边框宽度
```

**注意**：外描边会使坑位整体尺寸变大，设计时需考虑与相邻坑位的间距。

| 模糊半径 | 8 px |

| 规则 | 说明 |

### 3.7 生成规则

用户在设置区选择生成模式，系统根据标签页配置自动生成。

#### 3.7.1 单一文件夹循环

所有拼图标签页依次循环使用。

```
配置：
- 拼图1：4 个坑位
- 拼图2：2 个坑位

导入 15 张图片后：
┌────────┬─────────┬────────────────┬──────────────┐
│ 输出   │ 使用模板│ 消耗图片       │ 填充情况     │
├────────┼─────────┼────────────────┼──────────────┤
│ 第1张  │ 拼图1   │ 图1-4          │ ①②③④ 全满   │
│ 第2张  │ 拼图2   │ 图5-6          │ ①② 全满     │
│ 第3张  │ 拼图1   │ 图7-10         │ ①②③④ 全满   │  ← 循环
│ 第4张  │ 拼图2   │ 图11-12        │ ①② 全满     │  ← 循环
│ 第5张  │ 拼图1   │ 图13-15        │ ①②③ 有图    │
│        │         │                │ ④ 透明       │
└────────┴─────────┴────────────────┴──────────────┘
共输出: 5 张
```

**只有一个拼图时**：等同于单模板无限循环。

#### 3.7.2 封面 + 内页循环

拼图1 仅生成 1 次作为封面，拼图2、拼图3... 循环生成内页。

```
配置：
- 拼图1（封面）：4 个坑位
- 拼图2（内页）：2 个坑位
- 拼图3（内页）：3 个坑位

导入 15 张图片后：
┌────────┬─────────┬────────────────┬──────────────┐
│ 输出   │ 使用模板│ 消耗图片       │ 填充情况     │
├────────┼─────────┼────────────────┼──────────────┤
│ 第1张  │ 拼图1   │ 图1-4          │ ①②③④ 全满   │  ← 封面（仅1次）
│ 第2张  │ 拼图2   │ 图5-6          │ ①② 全满     │
│ 第3张  │ 拼图3   │ 图7-9          │ ①②③ 全满    │
│ 第4张  │ 拼图2   │ 图10-11        │ ①② 全满     │  ← 内页循环
│ 第5张  │ 拼图3   │ 图12-14        │ ①②③ 全满    │  ← 内页循环
│ 第6张  │ 拼图2   │ 图15           │ ① 有图       │
│        │         │                │ ② 透明       │
└────────┴─────────┴────────────────┴──────────────┘
共输出: 6 张
```

**只有一个拼图时**：该模式不可用（至少需要 2 个拼图）。

#### 3.7.3 循环规则说明

| 模式 | 规则 |
|------|------|
| **单一文件夹循环** | 拼图1 → 拼图2 → 拼图3 → 拼图1 → ...（全部循环） |
| **封面 + 内页循环** | 拼图1 仅 1 次，拼图2 → 拼图3 → 拼图2 → ...（后续循环） |
| **最后一页不足** | 空坑位保持透明（露出背景图） |

**未满足条件时**：「预览」按钮禁用（灰色），鼠标悬停显示提示。

### 5.6 背景图存储方案

背景图**复制到应用数据目录**，模板中存储相对路径引用：

| 项目 | 说明 |
|------|------|
| **存储位置** | `{用户数据目录}/PPT-Stitcher/backgrounds/` |
| **命名规则** | `{时间戳}_{原文件名}`，如 `1706000000_bg.png` |
| **模板引用** | 存储相对路径，如 `backgrounds/1706000000_bg.png` |
| **优点** | 体积小、加载快、模板可靠（原图移动不影响） |

**清理策略**：删除模板时，检查背景图是否被其他模板引用，无引用则删除文件。

**透明背景**：不存储背景图文件，仅保留画布尺寸与背景模式。

### 10.7 风险与注意事项

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 坑位交互复杂度高 | 开发周期延长 | 参考 Konva 源码实现核心交互 |
| Canvas 2D 性能 | 大量坑位时可能卡顿 | 限制最大坑位数、优化重绘策略 |
