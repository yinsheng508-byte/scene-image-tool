# 文字功能开发方案

## 一、功能概述

在 PPT 拼图排版模块的坑位操作区新增"添加文字"功能，支持用户在画布上添加、编辑、样式化文字。文字作为独立图层位于坑位之上，且随模板保存并在预览/导出中保持一致。

  return {

// 新增 redoStack
const redoStack = [];

function pushUndoState() {
  if (isRestoring) return;
  const puzzle = getCurrentPuzzle();
  if (!puzzle) return;

  const snapshot = {
    puzzleId: puzzle.id,
    ...cloneElements(puzzle),
    selectedSlotIds: [...AppState.selectedSlotIds],
    selectedTextIds: [...AppState.selectedTextIds]
  };

  undoStack.push(snapshot);
  if (undoStack.length > MAX_UNDO) undoStack.shift();

  // 新操作时清空重做栈
  redoStack.length = 0;
}

## 七、渲染逻辑

### 7.1 编辑模式渲染顺序

```
1. 清空画布
2. 应用视图变换（缩放、平移）
3. 绘制背景（颜色/图片/透明）
4. 绘制所有坑位
5. 绘制所有文字（按添加顺序，后加的在上层）
6. 如果有选中坑位，绘制坑位选中框和手柄
7. 如果有选中文字，绘制文字选中框、手柄和旋转手柄
```

### 7.2 文字绘制函数

```javascript
function drawText(ctx, textItem, isSelected) {
  ctx.save();

  // 计算文字边界框
  const bounds = measureTextBounds(ctx, textItem);

  // 移动到文字中心并旋转
  const centerX = textItem.x + bounds.width / 2;
  const centerY = textItem.y + bounds.height / 2;
  ctx.translate(centerX, centerY);
  ctx.rotate((textItem.rotation * Math.PI) / 180);
  ctx.translate(-bounds.width / 2, -bounds.height / 2);

  // 设置字体样式
  const { style } = textItem;
  const fontStyle = style.fontStyle === "italic" ? "italic" : "normal";
  const fontWeight = Number(style.fontWeight) || 400;
  ctx.font = `${fontStyle} ${fontWeight} ${style.fontSize}px "${style.fontFamily}"`;
  ctx.fillStyle = style.color;
  ctx.textBaseline = 'top';

  // 绘制多行文字（考虑换行、字间距、行间距）
  drawMultilineText(ctx, textItem, bounds);

  ctx.restore();
}
```

> `measureTextBounds` 需按实际换行、字间距、行间距计算宽高，否则选中框/命中检测会偏差。

### 7.3 多行文字处理

```javascript
function drawMultilineText(ctx, textItem, bounds) {
  const { content, width, style } = textItem;
  const { fontSize, letterSpacing, lineHeight, textAlign } = style;

  // 分行处理
  const lines = wrapText(ctx, content, width, letterSpacing);
  const actualLineHeight = fontSize * lineHeight;

  lines.forEach((line, index) => {
    const y = index * actualLineHeight;
    let x = 0;

    // 对齐处理
    const lineWidth = measureLineWidth(ctx, line, letterSpacing);
    if (textAlign === 'center') {
      x = (width - lineWidth) / 2;
    } else if (textAlign === 'right') {
      x = width - lineWidth;
    }

    // 逐字绘制（支持字间距）
    drawLineWithLetterSpacing(ctx, line, x, y, letterSpacing);
  });
}
```

### 7.4 预览和导出渲染

预览和导出使用完全相同的渲染逻辑，确保所见即所得：

```javascript
// preview-mode.js 修改
export async function drawPreview(ctx, task, backgroundImage, imageLoader, fontLoader, view) {
  // ... 现有代码 ...

  // 在坑位绘制完成后，绘制文字
  if (task.texts && task.texts.length > 0) {
    for (const textItem of task.texts) {
      await ensureFontLoaded(textItem.style.fontFamily, textItem.style.fontWeight, textItem.style.fontStyle, fontLoader);
      drawText(ctx, textItem, false);
    }
  }

  ctx.restore();
}
```

### 7.5 导出渲染策略（主进程）

当前导出使用 `sharp` 合成，无法直接绘制文字，需要先将文字渲染为透明 PNG 图层，再与坑位合成，且需复用同一套换行/对齐/字间距逻辑以保证一致性：

- 方案 A：引入 `node-canvas`，在主进程 `registerFont` 后绘制文字并导出 PNG buffer，再 `sharp(...).composite(...)`。
- 方案 B：用 SVG 生成文字（含 font-family/weight/letter-spacing/line-height），由 `sharp` 渲染为 buffer 参与合成。

### 8.2 字体加载器

```javascript
// puzzle/font-loader.js
const loadedFonts = new Set();

export async function loadFont(family, weight = 400, style = "normal") {
  const key = `${family}-${weight}-${style}`;
  if (loadedFonts.has(key)) return true;

  const config = FONT_CONFIG.find((f) =>
    f.family === family && f.weight === weight && (f.style || "normal") === style
  );
  if (!config) return false;

  if (config.type === "system") {
    loadedFonts.add(key);
    return true;
  }

  try {
    const fontUrl = new URL(`../fonts/${config.file}`, import.meta.url);
    const font = new FontFace(family, `url(${fontUrl})`, {
      weight: String(weight),
      style
    });
    await font.load();
    document.fonts.add(font);
    loadedFonts.add(key);
    return true;
  } catch (error) {
    console.error(`字体加载失败: ${family} ${weight}`, error);
    return false;
  }
}

export async function preloadAllFonts() {
  const promises = FONT_CONFIG
    .filter(f => f.type === "local")
    .map(f => loadFont(f.family, f.weight, f.style || "normal"));
  await Promise.all(promises);
}
```

## 十一、风险与注意事项

1. **字体文件体积**：单个字体文件 10-20MB，全部内置约 200MB+，需注意应用体积
2. **字体加载时机**：应在应用启动时预加载常用字体，其他字体按需加载避免首用卡顿
3. **平台字体可用性**：系统字体在不同平台差异较大，需按平台过滤并提供降级方案
4. **Canvas 文字渲染**：Canvas 不支持 letter-spacing，需逐字绘制实现
5. **旋转后的碰撞检测**：旋转后的文字边界框计算需要考虑旋转变换
6. **导出一致性**：主进程导出需与编辑渲染逻辑保持一致（node-canvas/SVG 方案验证）
7. **编辑模式冲突**：文字编辑时需屏蔽画布快捷键与拖拽，避免输入冲突
