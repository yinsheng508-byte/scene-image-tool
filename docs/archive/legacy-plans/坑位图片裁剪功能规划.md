# 坑位图片裁剪功能规划

> 创建日期: 2025-01-29
> 模块: 百变拼图排版
> 技术方案: 弹窗编辑

---

## 一、需求说明

### 1.1 功能目标

为坑位增加「裁剪设置」功能，用户可以：
1. 上传一张示例图片（仅当当前坑位已有图片时自动加载）
2. 通过拖拽和缩放定义裁剪规则
3. 系统记录变换值（缩放、偏移）
4. 生成时，所有填充到该坑位的图片都按此规则裁剪

### 1.2 核心特点

- **坑位级别设置**：裁剪规则是坑位的属性，应用到该坑位的所有图片
- **可选功能**：未设置裁剪的坑位，按现有 contain 居中模式处理
- **所见即所得**：弹窗预览、预览模式、导出生成使用同一渲染算法

### 1.3 参数范围

| 参数 | 范围 | 默认值 | 说明 |
|------|------|--------|------|
| scale | 0.5x ~ 3.0x | 1.0x | 图片缩放比例 |
| offsetX | -50% ~ +50% | 0% | 水平偏移（相对坑位宽度） |
| offsetY | -50% ~ +50% | 0% | 垂直偏移（相对坑位高度） |

### 1.4 设计约束

- **空白区域处理**：当 scale < 1.0 导致图片小于坑位时，空白区域为**透明**
- **宽高比假设**：建议填入同一坑位的图片保持相近的宽高比，以获得最佳裁剪效果
- **算法一致性**：弹窗编辑器、预览模式、导出生成必须使用同一个 `computeImageRect()` 函数
- **导出透明规则**：PNG 保持透明；导出 JPG 时，透明区域自动填充为拼图背景色
- **背景色来源**：导出 JPG 的填充色取拼图背景渲染结果；若未设置背景（颜色/图片），默认白色 `#FFFFFF`
- **参数边界**：scale、offsetX、offsetY 超出范围时需自动 clamp 回合法区间

### 3.4 操作方式

| 操作 | 效果 | 说明 |
|------|------|------|
| 点击坑位区域 | 上传图片 | 仅在当前坑位无图片时显示上传按钮 |
| 鼠标拖拽图片 | 调整偏移 | 上下左右移动图片位置 |

| 点击「更换图片」 | 重新选择 | 更换示例图片，重置裁剪参数 |
| 点击「确定」 | 保存设置 | 关闭弹窗，保存 crop 到坑位 |
| 点击「取消」 | 放弃修改 | 关闭弹窗，不保存 |

### 3.5 交互细节

**偏移限制**：
- 当图片尺寸 ≤ 坑位尺寸时（scale 较小），偏移操作无效果
- 此时界面提示："缩放较小，无法调整偏移"
- 偏移滑块/拖拽禁用状态

**滚轮缩放**：
- 弹窗内滚轮事件需调用 `e.preventDefault()` 阻止页面滚动
- 支持触控板双指缩放手势

**更换图片**：
- 更换后裁剪参数重置为默认值（scale=1.0，offsetX=0，offsetY=0）
- 可提示“已重置裁剪参数”

**取消/确定**：
- 取消：关闭弹窗，不保存本次修改（若已有裁剪，保留原值）
- 确定：保存当前裁剪参数到坑位

**加载失败**：
- 自动加载或手动上传失败时，提示“图片加载失败，请重新上传”
- 失败后回退为“无图片状态”，显示上传按钮

### 3.6 文案提示（建议）

- 无图片时：`点击上传示例图片`
- 偏移不可用：`缩放较小，无法调整偏移`
- 更换图片后：`已重置裁剪参数`
- 图片加载失败：`图片加载失败，请重新上传`
- 宽高比提示：`建议填入相近宽高比图片，效果更佳`

## 四、数据结构

### 4.1 Slot 对象扩展

```javascript
// desktop/renderer/puzzle/state.js

{
  id: string,
  x: number,
  y: number,
  w: number,
  h: number,
  style: {
    borderRadius: number,
    borderWidth: number,
    borderColor: string,
    shadow: boolean,
    lockAspect: boolean
  },

  // ===== 新增：裁剪设置 =====
  crop: {
    scale: number,    // 缩放比例，范围 0.5 ~ 3.0
    offsetX: number,  // 水平偏移，范围 -50 ~ +50（相对坑位宽度的百分比）
    offsetY: number   // 垂直偏移，范围 -50 ~ +50（相对坑位高度的百分比）
  } | null            // null = 未设置，使用默认 contain 模式
}
```

### 4.2 裁剪值含义

```
以坑位中心为原点：

scale（缩放）:
  0.5 = 图片缩小到 contain 基础尺寸的 50%（会出现透明空白）
  1.0 = 图片刚好完整显示（contain 模式）
  2.0 = 图片放大到 contain 基础尺寸的 200%

offsetX（水平偏移）- 相对坑位宽度的百分比:
   0% = 图片水平居中
 +50% = 图片向右移动坑位宽度的50%，显示图片左侧内容
 -50% = 图片向左移动坑位宽度的50%，显示图片右侧内容

offsetY（垂直偏移）- 相对坑位高度的百分比:
   0% = 图片垂直居中
 +50% = 图片向下移动坑位高度的50%，显示图片上部内容
 -50% = 图片向上移动坑位高度的50%，显示图片下部内容
```

### 4.3 偏移方向示意图

```
                      offsetY = -50%
                   （图片上移，显示下部）
                           ↑
                           │
                           │
    offsetX = -50%  ←──────●──────→  offsetX = +50%
   （图片左移，显示右部）   中心    （图片右移，显示左部）
                           │
                           │
                           ↓
                      offsetY = +50%
                   （图片下移，显示上部）
```

### 4.4 空白区域处理

当 `scale < 1.0` 时，图片可能小于坑位，产生空白区域：

```
┌─────────────────────┐
│ ▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒ │
│ ▒▒▒┌─────────┐▒▒▒▒▒ │
│ ▒▒▒│  图片   │▒▒▒▒▒ │  ▒ = 透明区域
│ ▒▒▒└─────────┘▒▒▒▒▒ │
│ ▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒ │
└─────────────────────┘
```

**处理方式**：空白区域为**透明**，显示拼图背景（背景图或背景色）；导出 JPG 时透明区域自动填充为拼图背景色（若无背景，默认白色）

## 五、渲染算法

### 5.1 算法流程

```
输入：
  - imageW, imageH：图片原始尺寸
  - slotW, slotH：坑位尺寸
  - crop：裁剪设置 { scale, offsetX, offsetY } 或 null

输出：
  - drawX, drawY：图片绘制起点（相对于坑位左上角）
  - drawW, drawH：图片绘制尺寸

步骤：
  1. 计算 contain 基础缩放
     baseScale = min(slotW / imageW, slotH / imageH)
     baseW = imageW * baseScale
     baseH = imageH * baseScale
```

### 5.2 代码实现

```javascript
// desktop/shared/puzzle-render-spec.mjs

/**
 * 计算图片在坑位中的绘制矩形
 * @param {number} imageW - 图片原始宽度
 * @param {number} imageH - 图片原始高度
 * @param {number} slotW - 坑位宽度
 * @param {number} slotH - 坑位高度
 * @param {object|null} crop - 裁剪设置 { scale, offsetX, offsetY }
 * @returns {object} - 绘制矩形 { x, y, w, h }
 */
export function computeImageRect(imageW, imageH, slotW, slotH, crop = null) {
  // 1. 计算 contain 基础尺寸
  const baseScale = Math.min(slotW / imageW, slotH / imageH);
  const baseW = imageW * baseScale;
  const baseH = imageH * baseScale;

  // 2. 无裁剪设置，默认居中
  if (!crop) {
    return {
      x: (slotW - baseW) / 2,
      y: (slotH - baseH) / 2,
      w: baseW,
      h: baseH
    };
  }

  // 3. 应用裁剪设置
  const scale = clamp(crop.scale ?? 1, 0.5, 3);
  const finalW = baseW * scale;
  const finalH = baseH * scale;

  // 4. 应用偏移（相对坑位尺寸的百分比）
  const offsetX = clamp(crop.offsetX ?? 0, -50, 50);
  const offsetY = clamp(crop.offsetY ?? 0, -50, 50);

  const pixelOffsetX = slotW * (offsetX / 100);
  const pixelOffsetY = slotH * (offsetY / 100);

  return {
    x: (slotW - finalW) / 2 + pixelOffsetX,
    y: (slotH - finalH) / 2 + pixelOffsetY,
    w: finalW,
    h: finalH
  };
}

function clamp(value, min, max) {
  return Math.max(min, Math.min(max, value));
}
```

## 九、注意事项

1. **算法一致性**：弹窗编辑器预览必须使用 `computeImageRect()` 同一函数，确保所见即所得
2. **圆角一致性**：弹窗中的坑位边框需显示实际圆角，与最终效果一致
3. **宽高比提示**：建议在界面上提示"填入该坑位的图片保持相近宽高比，效果更佳"
4. **空白透明**：scale < 1.0 时的空白区域为透明，显示拼图背景
5. **更换图片**：更换图片会重置裁剪参数（scale=1.0，offsetX=0，offsetY=0）
6. **导出 JPG 背景**：透明区域填充拼图背景渲染结果，未设置背景时默认白色 `#FFFFFF`
