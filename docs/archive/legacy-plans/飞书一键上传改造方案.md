# 飞书一键上传 — 完整改造方案

## 一、改造目标

| # | 目标 | 说明 |
|---|------|------|
| 1 | 模块改名 | 飞书随机上传 → 飞书一键上传 |
| 2 | 双模式 | 支持「随机上传」和「顺序上传」两种模式 |
| 3 | 多文件夹 | 可配置多个文件夹，每个独立设置模式和数量 |
| 4 | 一键执行 | 配置完成后一键上传所有文件夹到同一附件字段 |
| 5 | UI 重构 | 布局更清晰、高级、简洁 |

## 0.1 范围与非目标

**范围内**
- 飞书一键上传模块全量改造（UI + 逻辑 + IPC + main 端处理）。
- 同一附件字段合并写入，保留现有进度条/日志/错误翻译机制。

**非目标**
- 不做并行上传优化（保持串行稳定性）。
- 不新增新的飞书接口能力（仅复用现有 listFields/listRecords/upload/batchUpdate）。
- 不改造其他模块（导出、拼图、小红书等）。

## 二、关键决策（已确认）

| 问题 | 决策 |
|------|------|
| 顺序模式图片不足 | **循环复用**：图片用完后从头开始循环 |
| 顺序模式同一行内重复 | 当 `count > 文件数` 时允许同一行内重复（循环复用导致） |
| 排序规则 | **按文件名自然排序**：`localeCompare` + `numeric: true` |
| 多文件夹合并策略 | **合并写入**：每行将所有文件夹的图片合并后一次性写入同一附件字段 |
| 执行方式 | **串行处理**：按行处理；每行按配置顺序依次处理各文件夹 |
| 随机模式跨行重复 | 保持现有行为，允许跨行重复 |

## 2.1 交互规则补充

- 文件夹配置卡片默认模式：**顺序上传**。
- “每行数量”最小值 1，输入非法值自动回退为 1。
- 允许同一行内重复（仅顺序模式图片不足时出现），不做额外提示弹窗。
- 点击“取消”仅终止当前上传任务，不清空配置。

## 2.2 数据持久化策略

- 沿用现有本地存储：`feishuToken`、`feishuLink`、`feishuField`。
- **不持久化文件夹列表**（避免隐私路径落盘）。

## 四、数据模型设计

### 4.1 前端状态 (renderer.js)

```javascript
// 替代原有的 selectionState.imageFolder
const uploadState = {
  folders: [],       // FolderConfig[]
  nextFolderId: 1    // 自增ID
};

// 单个文件夹配置
// FolderConfig = {
//   id: number,                      // 唯一标识
//   path: string,                    // 文件夹绝对路径
//   mode: 'random' | 'sequential',  // 上传模式
//   count: number                    // 每行上传图片数
// }
```

### 4.2 IPC Payload

```javascript
// 新 payload (feishu:uploadImages)
{
  token: string,          // PersonalBaseToken
  link: string,           // 多维表格链接
  fieldName: string,      // 附件字段名
  startRow: number,       // 起始行
  endRow: number,         // 结束行
  folders: [              // 文件夹配置数组
    {
      path: string,       // 文件夹路径
      mode: 'random' | 'sequential',
      count: number       // 每行从该文件夹取几张
    }
  ]
}
```

### 4.3 核心计算公式

```
每行总图片数 = sum(folders[i].count)
总上传图片数 = (endRow - startRow + 1) * 每行总图片数
```

## 4.4 统一校验规则（前端与主进程一致）

- `token/link/field` 为空 → 直接阻断。
- `startRow/endRow` 不合法或 `end < start` → 阻断。
- `folders` 为空 → 阻断。
- 任意 `folder.path` 为空 → 阻断。
- `count < 1` → 自动修正为 1（前端），主进程仍需兜底校验。
- 随机模式：图片数量 < count → 阻断。
- 顺序模式：允许循环复用，不阻断。

### 5.4 随机模式 vs 顺序模式行为对比

```
文件夹内图片: [A.jpg, B.jpg, C.jpg, D.jpg, E.jpg]
配置: count=2, 行范围: row2~row4 (共3行)

═══════════════════════════════════════════════════

随机模式 (mode: random)
─────────────────────────────────────────────────
  row2 → pickRandom(2) → [C, A]      (每行独立随机)
  row3 → pickRandom(2) → [E, B]      (允许跨行重复)
  row4 → pickRandom(2) → [A, D]      (A 与 row2 重复，允许)

═══════════════════════════════════════════════════

顺序模式 (mode: sequential)
─────────────────────────────────────────────────
  排序后: [A.jpg, B.jpg, C.jpg, D.jpg, E.jpg]
  offset=0

  row2 → pick(offset=0, count=2) → [A, B]   offset → 2
  row3 → pick(offset=2, count=2) → [C, D]   offset → 4
  row4 → pick(offset=4, count=2) → [E, A]   offset → 6  ← 循环复用!

═══════════════════════════════════════════════════

顺序模式循环复用示例 (count=3, 仅2张图片)
─────────────────────────────────────────────────
  图片: [X.jpg, Y.jpg]

  row2 → pick(offset=0, count=3) → [X, Y, X]  ← 同一行内重复
  row3 → pick(offset=3, count=3) → [Y, X, Y]
  row4 → pick(offset=6, count=3) → [X, Y, X]
```

### 5.5 多文件夹合并写入示意

```
配置:
  文件夹A (随机, count=1): [风景1, 风景2, 风景3]
  文件夹B (顺序, count=2): [产品1, 产品2, 产品3, 产品4]
  行范围: row2~row3

═══════════════════════════════════════════════════

处理 row2:
  文件夹A → pickRandom(1) → [风景2]          ← 上传 → token_1
  文件夹B → pickSeq(offset=0, 2) → [产品1, 产品2]  ← 上传 → token_2, token_3
  合并写入: 附件字段 = [已有附件..., token_1, token_2, token_3]

处理 row3:
  文件夹A → pickRandom(1) → [风景1]          ← 上传 → token_4
  文件夹B → pickSeq(offset=2, 2) → [产品3, 产品4]  ← 上传 → token_5, token_6
  合并写入: 附件字段 = [已有附件..., token_4, token_5, token_6]

进度: total = 2行 × (1+2) = 6张
  1/6 风景2  2/6 产品1  3/6 产品2  4/6 风景1  5/6 产品3  6/6 产品4

═══════════════════════════════════════════════════

最终 batchUpdateRecords 一次性提交:
  records = [
    { record_id: "row2_id", fields: { "内容页图片": [...existing, t1, t2, t3] } },
    { record_id: "row3_id", fields: { "内容页图片": [...existing, t4, t5, t6] } }
  ]
```

async function getImageFilesSorted(folderPath) {
  const images = await getImageFiles(folderPath);
  images.sort((a, b) => {
    const nameA = path.basename(a).toLowerCase();
    const nameB = path.basename(b).toLowerCase();
    return nameA.localeCompare(nameB, 'zh-CN', { numeric: true, sensitivity: 'base' });
  });

}

function pickSequentialItems(list, count, offset) {
  if (list.length === 0) return [];
  const result = [];
  for (let i = 0; i < count; i++) {
    result.push(list[(offset + i) % list.length]);
  }
  return result;
}

### 9.3 新增: feishu:uploadImages handler

在原 `feishu:uploadRandom` handler (L2025) 之前添加新 handler：

```javascript
ipcMain.handle("feishu:uploadImages", async (event, payload) => {
  try {
    uploadAbortRequested = false;

    // ===== 1. 验证共享参数 =====
    const token = payload?.token;
    const link = payload?.link;
    const fieldName = payload?.fieldName;
    const startRow = Number(payload?.startRow);
    const endRow = Number(payload?.endRow);
    const folders = payload?.folders;

    if (!token || !link || !fieldName) {
      return { ok: false, error: "缺少授权码、表格链接或附件字段" };
    }
    if (!Number.isInteger(startRow) || !Number.isInteger(endRow)
        || startRow <= 0 || endRow < startRow) {
      return { ok: false, error: "行范围不合法" };
    }
    if (!Array.isArray(folders) || folders.length === 0) {
      return { ok: false, error: "请至少配置一个图片文件夹" };
    }

    const domain = payload?.domain || "https://base-api.feishu.cn";
    const { appToken, tableId, viewId } = parseBaseLink(link);

    // ===== 2. 加载各文件夹图片 =====
    const folderDataList = [];
    for (const fc of folders) {
      if (!fc.path) {
        return { ok: false, error: "存在未选择路径的文件夹配置" };
      }
      const count = Number(fc.count) || 1;
      if (count < 1) {
        return { ok: false, error: "每行上传图片数必须至少为1" };
      }

      // 根据模式加载图片（顺序模式排序，随机模式不排序）
      const images = fc.mode === 'sequential'
        ? await getImageFilesSorted(fc.path)
        : await getImageFiles(fc.path);

      if (images.length === 0) {
        return { ok: false, error: `文件夹 "${path.basename(fc.path)}" 内无可用图片` };
      }

      // 随机模式：图片数量 < count 则报错（顺序模式允许循环复用，不报错）
      if (fc.mode === 'random' && images.length < count) {
        return {
          ok: false,
          error: `文件夹 "${path.basename(fc.path)}" 图片数(${images.length})少于每行上传数(${count})`
        };
      }

      folderDataList.push({
        path: fc.path,
        mode: fc.mode,
        count,
        images,
        sequentialOffset: 0  // 顺序模式的位置追踪
      });
    }

    // ===== 3. 计算总数 =====
    const rowCount = endRow - startRow + 1;
    const imagesPerRow = folderDataList.reduce((sum, fd) => sum + fd.count, 0);
    const totalImages = rowCount * imagesPerRow;

    sendProgress("upload:progress", { phase: "start", total: totalImages });

    // ===== 4. 验证飞书字段（复用 listFields） =====
    const fields = await listFields(domain, token, appToken, tableId, viewId);
    const field = fields.find(item => item.field_name === fieldName);
    if (!field) return { ok: false, error: "未找到对应字段" };
    if (field.type !== 17) return { ok: false, error: "字段类型不是附件" };

    // ===== 5. 获取记录（复用 listRecords） =====
    const records = await listRecords(domain, token, appToken, tableId, viewId, endRow);
    if (records.length < endRow) {
      return { ok: false, error: "行范围超出记录数量" };
    }
    const recordIds = records.slice(startRow - 1, endRow).map(r => r.record_id);

    // ===== 6. 逐行处理 =====
    const updates = [];
    let successCount = 0;
    let imageIndex = 0;
    const failedFiles = [];

    for (let rowIdx = 0; rowIdx < recordIds.length; rowIdx++) {
      if (uploadAbortRequested) {
        sendProgress("upload:progress", { phase: "cancelled" });
        return { ok: false, cancelled: true };
      }

      const recordId = recordIds[rowIdx];
      const rowFileTokens = [];
      const existingAttachments = records[startRow - 1 + rowIdx].fields?.[fieldName] || [];

      // 按配置顺序遍历所有文件夹
      for (const fd of folderDataList) {
        // 根据模式选取图片
        let selectedForRow;
        if (fd.mode === 'sequential') {
          selectedForRow = pickSequentialItems(fd.images, fd.count, fd.sequentialOffset);
          fd.sequentialOffset += fd.count;  // 推进位置（自动循环）
        } else {
          selectedForRow = pickRandomItems(fd.images, fd.count);
        }

        // 上传选中的图片
        for (const filePath of selectedForRow) {
          if (uploadAbortRequested) {
            sendProgress("upload:progress", { phase: "cancelled" });
            return { ok: false, cancelled: true };
          }

          imageIndex++;
          sendProgress("upload:progress", {
            phase: "file-start",
            currentIndex: imageIndex,
            total: totalImages,
            fileName: path.basename(filePath)
          });
          logToRenderer(1,
            `上传图片 ${imageIndex}/${totalImages}: ${path.basename(filePath)} (第${rowIdx + 1}行)`
          );

          try {
            const parentType = getBitableParentType(filePath);
            const fileToken = await uploadDriveFile(
              domain, token, filePath, parentType, appToken
            );
            if (fileToken) {
              rowFileTokens.push({ file_token: fileToken });
              successCount++;
              sendProgress("upload:progress", {
                phase: "file-done",
                currentIndex: imageIndex,
                total: totalImages,
                fileName: path.basename(filePath)
              });
            } else {
              throw new Error("上传返回空 token");
            }
          } catch (error) {
            const errorInfo = serializeError(error);
            failedFiles.push({
              file: path.basename(filePath),
              error: errorInfo.message,
              code: errorInfo.code
            });
            logToRenderer(4,
              `上传失败: ${path.basename(filePath)} - ${errorInfo.message}`
            );
            sendProgress("upload:progress", {
              phase: "file-error",
              currentIndex: imageIndex,
              total: totalImages,
              fileName: path.basename(filePath),
              error: errorInfo.message,
              code: errorInfo.code
            });
          }
        }
      }

      // 合并所有文件夹的图片写入同一附件字段
      if (rowFileTokens.length > 0) {
        updates.push({
          record_id: recordId,
          fields: {
            [fieldName]: [...existingAttachments, ...rowFileTokens]
          }
        });
      }
    }

    // ===== 7. 批量更新记录（复用 batchUpdateRecords） =====
    if (updates.length > 0) {
      await batchUpdateRecords(domain, token, appToken, tableId, updates);
    }

    sendProgress("upload:progress", { phase: "done", total: totalImages });

    if (failedFiles.length > 0) {
      logToRenderer(3, `部分上传失败: ${failedFiles.length} 个文件失败`);
    }

    return {
      ok: true,
      uploaded: successCount,
      failed: failedFiles.length,
      recordIds
    };
  } catch (error) {
    return { ok: false, error: serializeError(error) };
  }
});
```
