# 强制更新功能改造方案

> 文档版本：1.0.0
> 创建日期：2026-02-04
> 适用项目：场景化图片工具 (桌面版)

---

## 一、改造背景与目标

### 1.1 背景

当前版本更新功能仅支持"推荐更新"模式，用户可以选择"稍后提醒"或"跳过此版本"。在某些场景下（如严重 Bug 修复、安全漏洞、API 不兼容变更），需要强制用户更新才能继续使用应用。

### 1.2 目标

在现有"版本更新提示"基础上增加"强制更新"模式，实现：

1. **不可跳过**：强制更新时用户无法关闭弹窗或点击"稍后提醒"
2. **每次启动自动弹出**：需要强制更新时，每次打开软件都自动弹出更新弹窗
3. **多触发点**：启动时、手动检查、密钥验证后均能触发
4. **离线兜底**：基于本地缓存，即使离线也能阻止旧版本使用
5. **优雅降级**：下载链接异常时提供手动复制方案

---

## 二、API 数据结构

### 2.1 UpdateInfo 字段定义

根据 `API_key.md` 文档，服务端返回的更新信息结构：

```typescript
interface UpdateInfo {
  has_update: boolean;      // 是否有新版本
  latest_version: string;   // 最新版本号 (如 "1.2.0")
  min_version?: string;     // 最低支持版本 (可选，如 "1.1.0")
  download_url: string;     // 下载地址
  update_log: string;       // 更新日志 (可能包含 \n 换行符)
  force_update?: boolean;   // 是否强制更新 (可选)
}
```

### 2.2 强制更新判定规则

客户端应按以下**任一条件**判定为强制更新（前提：`has_update === true`）：

| 条件 | 说明 |
|------|------|
| `force_update === true` | 服务端显式标记为强制更新 |
| `min_version` 存在且 `current_version < min_version` | 当前版本低于最低支持版本 |

**判定优先级**：
1. 若 `force_update === true`，直接判定为强制更新
2. 若 `min_version` 存在，进行版本比较
3. 版本解析失败时，若 `force_update === true` 仍强制更新

## 四、详细改造方案

### 4.1 版本比较工具函数

**文件位置**：`desktop/renderer/license/ui.js`

**新增函数**：

```javascript
/**
 * 版本号比较（语义化版本 SemVer）
 * @param {string} v1 - 版本号 A
 * @param {string} v2 - 版本号 B
 * @returns {number} -1: v1 < v2, 0: v1 = v2, 1: v1 > v2
 */
function compareVersions(v1, v2) {
  if (!v1 || !v2) return 0;

  // 移除 v 前缀
  const clean1 = String(v1).replace(/^v/i, '');
  const clean2 = String(v2).replace(/^v/i, '');

  const parts1 = clean1.split('.').map(p => parseInt(p, 10) || 0);
  const parts2 = clean2.split('.').map(p => parseInt(p, 10) || 0);

  const maxLen = Math.max(parts1.length, parts2.length);

  for (let i = 0; i < maxLen; i++) {
    const p1 = parts1[i] || 0;
    const p2 = parts2[i] || 0;

    if (p1 < p2) return -1;
    if (p1 > p2) return 1;
  }

  return 0;
}

/**
 * 判断是否为强制更新
 * @param {Object} updateInfo - API 返回的 update 字段
 * @param {string} currentVersion - 当前应用版本
 * @returns {Object} { isForce: boolean, reason: string }
 */
function resolveUpdatePolicy(updateInfo, currentVersion) {
  const result = {
    isForce: false,
    reason: '',
    hasUpdate: false,
    latestVersion: '',
    minVersion: '',
    downloadUrl: '',
    updateLog: ''
  };

  if (!updateInfo) return result;

  result.hasUpdate = !!updateInfo.has_update;
  result.latestVersion = updateInfo.latest_version || '';
  result.minVersion = updateInfo.min_version || '';
  result.downloadUrl = updateInfo.download_url || '';
  result.updateLog = updateInfo.update_log || '';

  if (!result.hasUpdate) return result;

  // 判定规则 1: force_update === true
  if (updateInfo.force_update === true) {
    result.isForce = true;
    result.reason = 'force_update';
    return result;
  }

  // 判定规则 2: min_version 存在且当前版本低于最低版本
  if (updateInfo.min_version && currentVersion) {
    const cmp = compareVersions(currentVersion, updateInfo.min_version);
    if (cmp < 0) {
      result.isForce = true;
      result.reason = 'min_version';
      return result;
    }
  }

  return result;
}

// 导出供外部使用（合并到现有 window.licenseUI 导出对象）
window.licenseUI = {
  bind,
  showLicenseModal,
  hideLicenseModal,
  showUpdateModal,
  hideUpdateModal,
  compareVersions,
  resolveUpdatePolicy
};
```

```json
    "latestVersion": "1.3.0",
    "minVersion": "1.1.0",

    "downloadUrl": "https://example.com/download/v1.3.0",
```

**新增字段说明**：

| `minVersion` | string | 最低支持版本（缓存） |

### 4.3 统一更新处理入口

**文件位置**：`desktop/renderer/license/index.js`

**新增方法**：`handleUpdateResponse(updateInfo, options)`

```javascript
/**
 * 统一处理更新响应
 * @param {Object} updateInfo - API 返回的 update 字段
 * @param {Object} options - 配置选项
 * @param {boolean} options.bypassSkip - 是否绕过跳过版本检查（原 force 参数）
 * @returns {boolean} 是否为强制更新
 */
async handleUpdateResponse(updateInfo, options = {}) {
  if (!updateInfo || !updateInfo.has_update) {
    // 清除强制更新标记 + 旧缓存
    if (this.config?.update) {
      this.config.update.forceRequired = false;
      this.config.update.forceReason = '';
      this.config.update.latestVersion = '';
      this.config.update.minVersion = '';
      this.config.update.downloadUrl = '';
      this.config.update.updateLog = '';
      this.config.update.forceUpdate = false;
      await this.saveConfig();
    }
    return false;
  }

  const { bypassSkip = false } = options;

  // 计算更新策略
  const policy = window.licenseUI?.resolveUpdatePolicy?.(
    updateInfo,
    this.currentVersion
  ) || { isForce: false };

  // 更新本地配置缓存
  this.config.update = this.config.update || {};
  Object.assign(this.config.update, {
    lastCheckTime: new Date().toISOString(),
    latestVersion: updateInfo.latest_version || '',
    minVersion: updateInfo.min_version || '',
    forceUpdate: !!updateInfo.force_update,
    downloadUrl: updateInfo.download_url || '',
    updateLog: updateInfo.update_log || '',
    forceRequired: policy.isForce,
    forceReason: policy.reason
  });

  // 强制更新时清除跳过版本
  if (policy.isForce) {
    this.config.update.skippedVersion = null;
  }
  // 最新版本变化时清除跳过版本
  else if (this.config.update.skippedVersion &&
           this.config.update.skippedVersion !== updateInfo.latest_version) {
    this.config.update.skippedVersion = null;
  }

  await this.saveConfig();

  // 检查是否跳过此版本（非强制更新时）
  const skipped = this.config.update.skippedVersion;
  if (!policy.isForce && !bypassSkip && skipped === updateInfo.latest_version) {
    return false;
  }

  // 显示更新弹窗
  this.showUpdateModal(updateInfo, { bypassSkip, isForceMode: policy.isForce });

  return policy.isForce;
}
```

### 4.6 修改 showUpdateModal 函数

**文件位置**：`desktop/renderer/license/ui.js`

**当前位置**：约第 60-82 行

**改造内容**：

```javascript
/**
 * 显示更新弹窗
 * @param {Object} updateInfo - 更新信息
 * @param {string} currentVersion - 当前版本
 * @param {Function} skipHandler - 跳过版本回调
 * @param {boolean} isForceMode - 是否为强制更新模式
 */
function showUpdateModal(updateInfo, currentVersion, skipHandler, isForceMode = false) {
  if (!updateModal || !updateInfo) return;

  activeUpdateInfo = updateInfo;
  onSkipUpdate = skipHandler;
  isForceUpdateMode = isForceMode;

  // 切换强制更新模式样式
  if (isForceMode) {
    updateModal.classList.add('force-mode');
  } else {
    updateModal.classList.remove('force-mode');
  }

  // 显示/隐藏最低版本提示
  const minVersionTip = document.getElementById('minVersionTip');
  const minVersionText = document.getElementById('minVersionText');

  if (minVersionTip) {
    // 仅当 min_version 触发强制更新时显示
    const policy = window.licenseUI?.resolveUpdatePolicy?.(updateInfo, currentVersion);
    if (policy?.isForce && policy?.reason === 'min_version' && updateInfo.min_version) {
      minVersionTip.style.display = 'block';
      if (minVersionText) {
        minVersionText.textContent = `v${updateInfo.min_version}`;
      }
    } else {
      minVersionTip.style.display = 'none';
    }
  }

  // 填充版本信息
  const updateCurrentVersion = document.getElementById('updateCurrentVersion');
  const updateLatestVersion = document.getElementById('updateLatestVersion');
  const updateLogText = document.getElementById('updateLogText');
  const updateSkipCheckbox = document.getElementById('updateSkipCheckbox');

  if (updateCurrentVersion) {
    updateCurrentVersion.textContent = currentVersion ? `v${currentVersion}` : '-';
  }
  if (updateLatestVersion) {
    updateLatestVersion.textContent = updateInfo.latest_version ? `v${updateInfo.latest_version}` : '-';
  }
  if (updateLogText) {
    updateLogText.textContent = updateInfo.update_log || '暂无更新说明';
  }
  if (updateSkipCheckbox) {
    updateSkipCheckbox.checked = false;
  }

  // 隐藏下载链接备用区域
  const downloadUrlFallback = document.getElementById('downloadUrlFallback');
  const downloadUrlText = document.getElementById('downloadUrlText');
  if (downloadUrlFallback) {
    downloadUrlFallback.style.display = 'none';
  }
  if (downloadUrlText) {
    downloadUrlText.value = '';
  }

  // 显示弹窗
  updateModal.classList.add('show');
}
```

### 4.7 修改关闭/稍后提醒逻辑

**文件位置**：`desktop/renderer/license/ui.js`

**当前位置**：约第 124-144 行

**改造内容**：

```javascript
// 模块级变量
let isForceUpdateMode = false;

// 在 bind() 中追加更新弹窗事件
function bind(manager) {
  activeManager = manager;
  // ... 现有授权弹窗逻辑 ...

  // ===== 更新弹窗事件（新增/修改） =====
  const updateModal = document.getElementById('updateModal');
  const updateCloseBtn = document.getElementById('updateCloseBtn');
  const updateLaterBtn = document.getElementById('updateLaterBtn');
  const updateNowBtn = document.getElementById('updateNowBtn');
  const copyUrlBtn = document.getElementById('copyUrlBtn');

  // 关闭按钮
  if (updateCloseBtn) {
    updateCloseBtn.addEventListener('click', () => {
      if (isForceUpdateMode) {
        showForceUpdateWarning();
        return;
      }
      hideUpdateModal();
    });
  }

  // 稍后提醒按钮
  if (updateLaterBtn) {
    updateLaterBtn.addEventListener('click', () => {
      if (isForceUpdateMode) {
        showForceUpdateWarning();
        return;
      }

      const skipCheckbox = document.getElementById('updateSkipCheckbox');
      if (skipCheckbox?.checked && activeUpdateInfo && onSkipUpdate) {
        onSkipUpdate(activeUpdateInfo.latest_version);
      }
      hideUpdateModal();
    });
  }

  // 立即更新按钮
  if (updateNowBtn) {
    updateNowBtn.addEventListener('click', async () => {
      const url = normalizeDownloadUrl(activeUpdateInfo?.download_url);

      if (!url) {
        // 链接无效时显示备用区域
        showDownloadUrlFallback(activeUpdateInfo?.download_url);
        return;
      }

      // 尝试打开链接
      if (window.licenseAPI?.openExternal) {
        const result = await window.licenseAPI.openExternal(url);

        if (result && result.ok === false) {
          // 打开失败时显示备用区域
          showDownloadUrlFallback(url);
          return;
        }
      }

      // 非强制更新时允许跳过并关闭弹窗
      if (!isForceUpdateMode) {
        const skipCheckbox = document.getElementById('updateSkipCheckbox');
        if (skipCheckbox?.checked && activeUpdateInfo && onSkipUpdate) {
          onSkipUpdate(activeUpdateInfo.latest_version);
        }
        hideUpdateModal();
      }
      // 强制更新时保持弹窗打开，提示用户完成更新后重启
    });
  }

  // 复制链接按钮
  if (copyUrlBtn) {
    copyUrlBtn.addEventListener('click', () => {
      const urlInput = document.getElementById('downloadUrlText');
      if (urlInput) {
        const text = urlInput.value || '';
        if (navigator.clipboard?.writeText) {
          navigator.clipboard.writeText(text).then(() => {
            window.showToast?.('链接已复制到剪贴板', 'success');
          });
        } else {
          urlInput.select();
          document.execCommand('copy');
          window.showToast?.('链接已复制到剪贴板', 'success');
        }
      }
    });
  }

  // 遮罩层点击（updateModal 本身就是 backdrop）
  if (updateModal) {
    updateModal.addEventListener('click', (event) => {
      if (event.target !== updateModal) return;
      if (isForceUpdateMode) {
        showForceUpdateWarning();
        return;
      }
      hideUpdateModal();
    });
  }

  // ESC 键关闭
  document.addEventListener('keydown', (e) => {
    if (e.key === 'Escape' && updateModal?.classList.contains('show')) {
      if (isForceUpdateMode) {
        e.preventDefault();
        showForceUpdateWarning();
        return;
      }
      hideUpdateModal();
    }
  });
}

/**
 * 显示强制更新警告
 */
function showForceUpdateWarning() {
```

### 4.8 启动时强制更新自动弹窗

**文件位置**：`desktop/renderer/license/index.js`

**改造位置**：`LicenseManager.init()` 方法

**核心逻辑**：
> **重要**：如果需要强制更新，每次打开软件都必须自动弹出更新弹窗，直到用户完成更新。

**实现流程**：

```
应用启动
    ↓
读取本地配置 (forceRequired 字段)
    ↓
检查是否需要强制更新
    ├─ 是 → 自动弹出更新弹窗 + 禁用主界面
    └─ 否 → 正常启动
```

**新增逻辑**：

```javascript
async init() {
  // ... 现有初始化代码 ...

  // 读取本地配置
  await this.loadConfig();

  // 先绑定弹窗事件，避免自动弹窗时按钮无响应
  if (window.licenseUI?.bind) {
    window.licenseUI.bind(this);
  }

  // 获取当前版本
  if (window.licenseAPI?.getVersion) {
    try {
      this.currentVersion = await window.licenseAPI.getVersion();
    } catch (error) {
      this.currentVersion = '';
    }
  }

  // ========== 核心：启动时强制更新自动弹窗 ==========
  // 每次打开软件都检查，如需强制更新则自动弹出
  if (this.config?.update?.forceRequired) {
    // 基于缓存的更新信息重建 updateInfo
    const cachedUpdate = {
      has_update: true,
      latest_version: this.config.update.latestVersion,
      min_version: this.config.update.minVersion,
      download_url: this.config.update.downloadUrl,
      update_log: this.config.update.updateLog,
      force_update: this.config.update.forceUpdate
    };

    // 重新计算是否仍需强制更新（版本可能已手动更新）
    const policy = window.licenseUI?.resolveUpdatePolicy?.(
      cachedUpdate,
      this.currentVersion
    );

    if (policy?.isForce) {
      // 【每次启动都执行】仍需强制更新，自动弹出更新弹窗
      this.showUpdateModal(cachedUpdate, { bypassSkip: true, isForceMode: true });
      this.disableMainUI();
      // 注意：不 return，允许继续初始化其他组件，但主界面被禁用
    } else {
      // 版本已满足要求，清除强制更新标记
      this.config.update.forceRequired = false;
      this.config.update.forceReason = '';
      await this.saveConfig();
      this.enableMainUI();
    }
  }
  // ========== 核心逻辑结束 ==========

  // ... 继续现有初始化流程 ...
}

/**
 * 禁用主界面（强制更新时）
 */
disableMainUI() {
  // 检查是否已存在遮罩
  if (document.getElementById('forceUpdateOverlay')) return;

  const overlay = document.createElement('div');
  overlay.id = 'forceUpdateOverlay';
  overlay.style.cssText = `
    position: fixed;
    top: 0;
    left: 0;
    width: 100%;
    height: 100%;
    background: rgba(0, 0, 0, 0.6);
    z-index: 9998;
    pointer-events: all;
    display: flex;
    align-items: center;
    justify-content: center;
  `;

  overlay.innerHTML = `
    <div style="
      background: white;
      padding: 30px;
      border-radius: 8px;
      text-align: center;
      max-width: 400px;
    ">
      <div style="font-size: 48px; margin-bottom: 15px;">⚠️</div>
      <h2 style="margin: 0 0 10px; color: #333;">版本过旧</h2>
      <p style="margin: 0; color: #666;">当前版本已停止服务，请更新后继续使用</p>
    </div>
  `;

  document.body.appendChild(overlay);
}

/**
 * 移除主界面禁用遮罩
 */
enableMainUI() {
  const overlay = document.getElementById('forceUpdateOverlay');
  if (overlay) {
    overlay.remove();
  }
}
```

## 五、强制更新弹窗触发规则

### 5.1 核心规则：每次启动自动弹窗

> **重要**：如果需要强制更新，**每次打开软件都必须自动弹出更新弹窗**，直到用户完成更新。

**触发时机**：

```
┌─────────────────────────────────────────────────────────────┐
│                      应用启动流程                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   应用启动                                                   │
│      ↓                                                      │
│   读取本地配置                                               │
│      ↓                                                      │
│   检查 forceRequired 标记                                   │
│      ↓                                                      │
│   ┌─────────────┐                                           │
│   │ forceRequired │                                         │
│   │   = true?    │                                          │
│   └──────┬──────┘                                           │
│          │                                                   │
│    ┌─────┴─────┐                                            │
│    ↓           ↓                                            │
│   是          否                                             │
│    ↓           ↓                                            │
│  【自动弹出     正常启动                                     │
│   更新弹窗】                                                 │
│    ↓                                                        │
│  禁用主界面                                                  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**行为说明**：

| 场景 | 弹窗行为 | 主界面状态 |
|------|----------|------------|
| 首次检测到强制更新 | 立即弹出 | 禁用 |
| 关闭软件后再次打开（未更新） | **自动弹出** | 禁用 |
| 连续重启多次（未更新） | **每次都自动弹出** | 禁用 |
| 更新完成后首次启动 | 不弹出 | 正常 |

### 5.2 触发点清单

#### 需要调用 handleUpdateResponse 的位置

| 触发点 | 文件位置 | 说明 |
|--------|----------|------|
| `verify()` 返回后 | `desktop/renderer/license/index.js` | 成功验证且有更新时统一走 `handleUpdateResponse` |
| `checkUpdate()` 返回后 | `desktop/renderer/license/index.js` | 手动检查时 `bypassSkip: true`，仍复用 `handleUpdateResponse` |
| `init()` 启动时 | `desktop/renderer/license/index.js` | **每次启动都检查缓存 `forceRequired`，必要时自动弹窗（先 bind 再 show）** |

> 建议在 `verify()` / `checkUpdate()` 返回后**无论 update 是否为空**都调用 `handleUpdateResponse`，以清理历史缓存的 `forceRequired`。

### 5.3 参数名称统一

当前代码中 `showUpdateModal` 的 `force` 参数含义是"绕过跳过版本"，为避免与"强制更新"混淆，建议：

- 将原 `force` 参数重命名为 `bypassSkip`
- 新增 `isForceMode` 参数表示"强制更新模式"（传递到 `window.licenseUI.showUpdateModal`）

示例（`desktop/renderer/license/index.js`）：

```javascript
showUpdateModal(updateInfo, options = {}) {
  if (!updateInfo) return;
  const { bypassSkip = false, isForceMode = false } = options;
  const skipped = this.config?.update?.skippedVersion;
  if (!isForceMode && !bypassSkip && skipped && updateInfo.latest_version === skipped) return;

  window.licenseUI?.showUpdateModal(
    updateInfo,
    this.currentVersion,
    (version) => {
      if (!version) return;
      this.config.update = this.config.update || {};
      this.config.update.skippedVersion = version;
      this.saveConfig();
    },
    isForceMode
  );
}
```

## 六、边界情况处理

### 6.1 已跳过版本变为强制更新

**场景**：用户之前跳过了 v1.2.0，但服务端将 v1.2.0 设为强制更新

**处理**：强制更新时忽略 `skippedVersion`，在 `handleUpdateResponse` 中清除

### 6.2 最新版本变化时清除跳过记录

**场景**：用户跳过了 v1.2.0，服务端发布了 v1.3.0

**处理**：在 `handleUpdateResponse` 中检测版本变化，自动清除 `skippedVersion`

### 6.3 download_url 无效

**场景**：下载链接为空或无法打开

**处理**：
1. `normalizeDownloadUrl` 校验失败即判定无效（含 `file:` / 本地路径）
2. 显示手动复制区域
3. 仍保持弹窗打开（强制更新时）
4. 提示用户联系客服

### 6.4 min_version 无法解析

**场景**：`min_version` 格式异常（如 "latest"）

**处理**：仅依据 `force_update` 字段判定，版本比较返回 0

### 6.5 离线场景

**场景**：网络请求失败，无法获取最新更新信息

**处理**：
1. 基于本地缓存的 `forceRequired` 标记判断
2. 若为 true，仍触发强制更新弹窗
3. 下载链接使用缓存的 `downloadUrl`

## 九、风险评估

| 风险项 | 风险等级 | 缓解措施 |
|--------|----------|----------|
| 下载链接失效导致用户无法更新 | 高 | 提供手动复制功能和客服联系方式 |
| 误判强制更新导致用户无法使用 | 高 | 版本比较逻辑需充分测试 |
| 本地缓存被篡改绕过强制更新 | 中 | 建议后续增加签名校验 |
| 强制更新遮罩层覆盖弹窗导致无法点击 | 中 | 遮罩层 z-index 低于 `modal-backdrop`，仅阻断底层 UI |
| 网络波动导致频繁弹窗 | 低 | 基于缓存，单次会话内不重复弹窗 |
