## 产品简介

流量蜂虚拟笔记工具是一款专为内容创作者、电商运营和自媒体人设计的一站式图片处理工作台，集成文档转图、场景合成、拼图排版、飞书上传及商品图片下载等功能。

**核心功能一览：**

| 功能模块 | 用途说明 |
|---------|---------|
| 文档一键导出 | Word / PPT / PDF 批量转 PNG，支持清晰度倍率、页数限制、子文件夹输出 |
| 场景化图片排版 | 上传场景图与叠图，拖动四角定位后导出高清透视合成图，支持专业混合模式 |
| 百变拼图排版 | 定义模板坑位，批量填充图片生成成品图，支持文字、贴纸元素，多页模板管理 |
| 飞书一键上传 | 支持分模块上传和按笔记上传，批量写入飞书多维表格附件字段 |
| 小红书商品下载 | 输入商品链接，自动抓取主图与详情图并保存到本地 |

**自动记忆：** 软件自动保存上次使用的所有输入与路径配置，重新打开可继续上次工作。

## 安装与环境要求

### 安装步骤

1. 下载安装包（`.exe` 文件）
2. 双击运行安装程序，按向导完成安装（支持自定义安装目录）

| 依赖项 | 说明 |
|-------|------|
| 操作系统 | Windows 10 64位及以上 |
| LibreOffice | **Full 版默认内置运行时，无需单独安装**；若运行时异常，可在弹窗点击「下载 LibreOffice」进行备用修复 |

> **提示：** 导出失败时可先点击「重新检测」，并使用「复制诊断信息」将运行时来源与错误码发给开发者排查。

## 首次使用流程

### 微信登录

首次使用时，软件会弹出微信扫码登录弹窗：

1. 扫描弹窗中的二维码，关注公众号「**尹星河**」
2. 在公众号中发送「**登录**」，获取 6 位数字验证码
3. 在弹窗中输入验证码，点击「**登录并进入**」

> 登录成功后，该设备将记住登录状态，后续启动不再提示。若需重新验证，可在弹窗中点击「重试检查」。

### 授权激活

首次激活后，每个功能模块可**免费试用 5 次**。试用次数用尽后，会弹出授权弹窗：

1. 扫描弹窗中的二维码，从公众号获取授权密钥（格式：`LLF-XXXX-XXXX-XXXX`）
2. 在输入框中填入授权密钥
3. 点击「**验证并激活**」
4. 验证成功后即可无限制使用

> 也可以在「**设置**」页面的「授权管理」区域主动输入并验证授权密钥。

### 版本更新

软件启动时会检查是否有新版本可用：

- **普通更新**：可选择「立即更新」或「稍后提醒」；勾选「不再提示此版本」可跳过当前版本
- **强制更新**：当前版本低于最低支持版本时，必须更新后才能继续使用

点击「立即更新」后，系统将打开下载链接；若无法自动打开，弹窗中会显示下载地址供手动复制。

## 文档一键导出

**用途：** 将 Word、PPT、PDF 文档批量转换为高清 PNG 图片，适合文档转素材、课件转图、内容发布等场景。

**支持格式：** `.doc` `.docx` `.ppt` `.pptx` `.pdf`

### 操作步骤

**第一步：添加文件**

- 点击「**选择文件**」：添加单个或多个文档文件
- 点击「**选择文件夹**」：批量扫描整个目录（含子文件夹）
- 选择后界面显示「文件数」和「文件夹数」统计，以及扫描到的文件列表
- 点击「**清空选择**」可重置所有已添加的文件

**第二步：选择输出目录**

点击「**选择图片输出目录**」，指定图片的保存位置（必填）。

**第三步：调整导出设置**

| 设置项 | 选项 | 说明 |
|-------|------|------|
| 清晰度倍率 | 1x / 1.5x / 2x / 3x | 倍率越高越清晰，文件越大；推荐 2x |
| 导出前几页 | 数字或留空 | 填入数字仅导出指定页数；留空则导出全部 |
| 输出到子文件夹 | 勾选/不勾选 | 勾选后每个文档的图片存入独立文件夹（推荐勾选） |

**第四步：开始导出**

点击「**开始导出**」，进度条实时显示当前文件和整体百分比。导出过程中可点击「**取消**」中止任务。

### 文件命名规则

| 设置 | 命名格式 | 示例 |
|-----|---------|------|
| 勾选「输出到子文件夹」 | `输出目录/文件名/文件名-页码.png` | `D:\导出\课程\课程-001.png` |
| 不勾选 | `输出目录/文件名-扩展名-页码.png` | `D:\导出\课程-pptx-001.png` |

> 页码从 `001` 开始三位编号，自动确保不与已有文件名冲突。

### 使用示例

**场景：** 将 20 页产品介绍 PPT 导出为高清图片

1. 点击「选择文件」，选择 `产品介绍.pptx`
2. 点击「选择图片输出目录」，选择 `D:\导出`
3. 清晰度倍率选 `2x`，勾选「输出到子文件夹」
4. 点击「开始导出」
5. 完成后在 `D:\导出\产品介绍` 文件夹中找到 20 张高清 PNG

## 场景化图片排版

**用途：** 将截图或海报嵌入到场景背景中（如手机屏幕、电脑显示器、相框），自动处理透视变形，制作逼真的样机效果图。

### 操作步骤

**第一步：上传底图**

点击「**1. 上传底图（场景图）**」，选择带有屏幕或相框的场景照片。上传后画布中央会出现带四个角点的蓝色矩形框。

**第二步：定位贴合区域**

- 拖动四个角点，对齐到场景中目标区域的四个角（如手机屏幕四角）
- **画布缩放：** 按住 `Ctrl` + 滚动鼠标滚轮，可放大缩小画布，便于像素级精细定位
- 点击「**重置四个角**」可将角点恢复到初始位置

**第三步：上传叠图**

点击「**2. 上传叠图图片（可多选）**」，选择要嵌入的图片（支持一次选择多张）。右侧预览区会列出所有已上传的叠图，点击可切换当前预览。

**第四步：调整效果（可选）**

| 设置 | 说明 |
|-----|------|
| 不透明度 | 调整叠图透明程度（0–100%） |
| 混合模式 | 选择图片与背景的混合方式（见下表） |

**混合模式说明：**

| 模式 | 效果 | 适用场景 |
|-----|------|---------|
| 正常 (Normal) | 直接覆盖 | 常规合成 |
| 正片叠底 (Multiply) | 颜色相乘，整体变暗 | 叠加纹理效果 |
| 滤色 (Screen) | 颜色相加，整体变亮 | 添加光效 |
| 叠加 (Overlay) | 增强对比度 | 保留底图明暗 |
| 柔光 (Soft Light) | 柔和增强对比 | 自然融合效果 |

> 混合模式采用 WebGL 实现，含 sRGB Gamma 修正，效果与 Photoshop 一致。

**第五步：选择保存位置**

点击「**3. 选择文件保存位置**」，指定合成图的输出目录。

**第六步：导出**

点击「**导出全部**」，批量生成所有叠图的合成效果图。

### 导出说明

- 输出格式：PNG，分辨率通常为 2K–4K，自动压缩至 10MB 以内
- 单张叠图：导出为 `底图名_output.png`（直接输出到保存目录）
- 多张叠图：在保存目录下生成 `底图名` 子文件夹（重名自动变为 `底图名（1）`），文件命名为 `底图名001.png`、`底图名002.png`…

### 使用示例

**场景：** 制作 APP 界面在手机中的展示效果图

1. 上传「手持 iPhone」的场景照片作为底图
2. 拖动四个角点精确对齐到 iPhone 屏幕四角
3. 上传 5 张 APP 截图作为叠图
4. 混合模式选「正常」，不透明度保持 100%
5. 点击「导出全部」，获得 5 张合成好的样机效果图

## 百变拼图排版

**用途：** 创建自定义拼图模板，批量填充图片生成成品图。支持添加文字和贴纸装饰元素，适合制作小红书笔记图、商品展示图、宫格图等。

### 界面布局

- **左侧工具栏**：画布设置、坑位操作、元素操作、文件操作、生成规则、导出按钮及属性面板
- **中央画布**：所见即所得编辑区，支持多标签页
- **顶部标签栏**：多页模板管理，以及保存/加载/删除模板
- **底部图片列表**：已导入的素材图片和预计生成数量

### 画布操作

在「**画布操作**」区域设置背景和尺寸：

| 操作 | 说明 |
|-----|------|
| 上传背景图 | 使用图片作为背景（支持 PNG、JPG 等格式） |
| 透明背景 | 勾选后生成透明底 PNG |
| 纯色背景 | 勾选后使用纯色底，点击色块可选色 |
| 宽 / 高 | 设置画布像素尺寸，默认 1242×1656 |

**常用画布尺寸参考：**

| 平台 | 推荐尺寸 | 比例 |
|-----|---------|------|
| 小红书竖图 | 1242×1656 | 3:4 |
| 朋友圈 / 微博 | 1080×1080 | 1:1 |
| 详情页长图 | 750×自定义高度 | — |

### 坑位操作

坑位是图片的占位区域，生成时会按顺序自动填充图片。

**添加坑位：**

| 按钮 | 说明 |
|-----|------|
| 添加坑位 | 创建默认方形坑位，居中放置 |
| 添加图片坑位 | 选择一张图片，自动按图片比例创建坑位并锁定比例 |
| 清空坑位 | 删除当前页所有坑位 |

**编辑坑位（选中后）：**

- **移动**：拖动坑位主体
- **缩放**：拖动坑位四周的控制点
- **右键菜单**：复制坑位 / 删除坑位 / 移至顶层 / 移至底层

**坑位属性**（选中坑位后右侧属性面板显示）：

| 属性 | 说明 |
|-----|------|
| W / H | 坑位宽度和高度（像素，单选可编辑） |
| 锁定比例 | 调整大小时保持宽高比（单选可编辑） |
| 圆角 | 设置圆角半径（0 为直角） |
| 边框 | 边框粗细（0–20px）和边框颜色 |
| 阴影 | 勾选后添加投影效果 |
| 裁剪设置 | 精细控制图片在坑位内的填充方式（单选可编辑，见下文） |
| 复制 / 删除 | 操作当前选中坑位 |

**多选操作**（按住 `Shift` 点击或 `Alt + 拖动` 套索选择多个坑位）：

- 左对齐 / 右对齐 / 上对齐 / 下对齐
- 水平居中 / 垂直居中
- 水平等距分布 / 垂直等距分布
- 整体缩小 / 放大
- 批量设置圆角 / 边框粗细 / 边框颜色 / 阴影（一次修改对所有选中坑位同时生效）

> 交互说明：属性输入框修改后，点击画板或任意其他区域会自动提交新值，无需按 `Enter`。

**裁剪设置：**

点击「**裁剪设置**」打开裁剪弹窗：
1. 点击「点击上传示例图片」预览效果
2. 滚轮缩放图片比例；拖动调整水平/垂直偏移
3. 支持直接输入「缩放」「水平」「垂直」精确数值
4. 点击「确定」应用；点击「重置」恢复默认
5. 右侧属性面板显示裁剪参数摘要，点击「清除」可移除裁剪设置

### 元素操作

文字和图片元素会固定显示在所有生成的图片上（不参与批量替换），适合做标题、贴纸、装饰。

**文字元素：**

1. 点击「**添加文字**」创建文字框（默认显示"双击编辑"）
2. 双击文字进入编辑模式，输入或修改内容
3. 按 `Esc` 或点击空白处结束编辑
4. 在右侧文字属性面板调整：

| 属性 | 可设置内容 |
|-----|---------|
| 字体 | 内置字体 + 系统字体（自动读取本机已安装字体，优先显示中文字体名） |
| 字重 | 内置字体按字体提供；系统字体提供 400 / 700 |
| 字号 | 8–200px |
| 样式 | 加粗（B）/ 斜体（I） |
| 颜色 | 颜色拾色器 |
| 对齐 | 左对齐 / 居中 / 右对齐 |
| 字间距 | -10–50px |
| 行间距 | 1.0–3.0 倍 |
| 描边 | 描边色 + 描边粗细（0–20px） |
| 阴影 | 阴影色 + 模糊（0–20px）+ 偏移 X/Y（-20~20px） |
| 缩放 | − / + 按钮快速调整大小 |

5. 拖动文字移动位置；拖动角点缩放；拖动顶部旋转控制点旋转

> 说明：文字编辑框（双击后输入状态）用于编辑内容，描边/阴影以画布最终渲染效果为准。

**图片元素（贴纸）：**

1. 点击「**添加图片**」选择图片文件
2. 图片自动居中放置，保持原始宽高比
3. 拖动移动位置；拖动角点等比缩放；拖动旋转控制点旋转
4. 点击「**清空图片**」删除当前页所有图片元素

### 导入图片素材

**单一文件夹循环模式（默认）：**

1. 点击「**上传图片**」，选择图片文件或整个文件夹（自动扫描子文件夹并按文件名自然排序）
2. 图片显示在底部「图片列表」中
3. 可拖拽图片调整顺序（顺序即填充顺序）
4. 点击图片右侧的 × 可删除单张；「**清空全部**」删除所有
5. 可选：勾选「**拼图1作为封面（仅生成1张）**」，首张仅使用拼图1，后续从拼图2开始循环

**多文件夹模式：**

1. 在「生成规则」区选择「**多文件夹模式**」
2. 点击「**选择文件夹**」，在弹窗中为每个拼图页分别绑定文件夹
3. 可勾选「支持输出到子文件夹中」，让每页结果存入独立子文件夹
4. 未选文件夹的拼图页不参与生成

### 多页模板

- 点击「**+ 新建**」添加新页（最多 10 页）
- 点击页签右侧 × 删除当前页（需确认）
- 点击「**保存模板**」将当前所有页配置保存为命名模板
- 在下拉框中选择已保存模板快速套用
- 点击「**···**」菜单中的「重命名」「复制模板」或「迁移模板库」进行进一步管理
- 点击「**迁移模板库**」会先弹出迁移说明，确认后可一键打开模板文件夹；迁移时建议完整复制 `PPT-Stitcher` 文件夹，避免模板参数或图片丢失
- 点击「**删除模板**」移除不需要的模板

> 软件每 10 秒自动保存一次当前编辑状态，切换标签或关闭软件前状态不会丢失。

### 生成规则

| 规则 | 说明 |
|-----|------|
| 单一文件夹循环 | 图片列表按顺序依次填充所有坑位，图片数量多于坑位数时自动生成多张 |
| 拼图1作为封面（仅生成1张） | 仅在「单一文件夹循环」下可用。拼图1只生成首张，拼图2及后续页参与循环 |
| 多文件夹模式 | 每个拼图页仅使用其绑定文件夹中的图片填充 |

> 图片不足时，剩余坑位留空。底部「预计生成 X 张」实时显示估算结果。

### 预览与生成

1. 点击「**预览**」进入预览模式（编辑功能锁定）
2. 预览默认使用「**精确预览（导出同源）**」，效果与最终导出保持一致
3. 点击「◀」「▶」切换每一张预计生成的成品图
4. 右下角可用 − / + 按钮或 `Ctrl + 滚轮` 缩放预览画面；也可用「**适配**」「**1:1**」快速切换

## 飞书一键上传

**用途：** 将本地图片批量上传到飞书多维表格的附件字段中，支持「分模块上传」和「按笔记上传」两种模式。

### 准备工作

1. 在飞书中创建多维表格，添加一个「**附件**」类型的字段
2. 获取 PersonalBaseToken：
   - 打开多维表格 → 右上角「···」→「更多」→「API」
   - 复制 PersonalBaseToken
3. 复制包含 `table` 和 `view` 参数的完整表格链接

### 操作步骤

**第一步：填写基本配置**

| 字段 | 说明 |
|-----|------|
| 授权码 | PersonalBaseToken（点击「显示/隐藏」切换可见性） |
| 表格链接 | 完整的多维表格 URL |
| 飞书附件字段 | 字段名称，必须与表格中完全一致（如「内容页图片」） |
| 表格起始行 | 从第几行开始写入（通常从第 2 行开始，第 1 行是表头） |
| 表格结束行 | 写入到第几行结束 |

**第二步：选择上传模式**

上传模式为左右 Tab 切换：

| 模式 | 适用场景 |
|-----|---------|
| 分模块上传 | 从多个图片模块文件夹中按顺序或随机取图，每行合并写入固定数量图片 |
| 按笔记上传 | 一个入口文件夹下包含多个笔记子文件夹，每个最下层子文件夹作为一篇笔记写入一行 |

默认进入「分模块上传」，旧版上传流程保持不变。

**第三步：配置图片来源**

### 分模块上传

点击「**+ 添加文件夹**」，每次添加一个文件夹配置项，可添加多个：

| 配置项 | 说明 |
|-------|------|
| 选择文件夹 | 选择本地图片文件夹（只读取该文件夹直接下的图片，不扫描子文件夹） |
| 顺序上传 | 按文件名自然排序依次选取图片，循环复用 |
| 随机上传 | 随机从该文件夹中抽取图片 |
| 每行 X 张 | 该文件夹每行写入几张图片 |

> **多文件夹合并规则：** 每行上传的总图片数 = 各文件夹「每行张数」之和。例如：文件夹 A 配置 2 张顺序上传 + 文件夹 B 配置 1 张随机上传，则每行合计写入 3 张图片。

### 按笔记上传

切换到「**按笔记上传**」后，可以选择一个父文件夹，也可以追加多个入口文件夹：

| 操作 | 说明 |
|-----|------|
| 选择父文件夹 | 替换当前入口列表，并自动扫描该文件夹下的笔记 |
| 添加多个子文件夹 | 追加多个入口文件夹，并自动扫描 |
| 重新扫描 | 重新按当前入口列表扫描，恢复之前从待上传列表删除的笔记 |
| 删除笔记 | 仅从本次待上传列表移除，不删除本地文件夹 |

扫描规则：

- 最下层子文件夹作为一篇笔记
- 入口顺序由选择或追加顺序决定，入口内部按文件夹名自然排序
- 每篇笔记内只读取该文件夹直接包含的图片，并按文件名自然排序
- 空的最下层子文件夹会跳过，不占用飞书行
- 如果入口有子目录，入口根部图片会被忽略
- 如果中间层文件夹同时包含图片和子文件夹，中间层图片也会被忽略
- 如果入口没有子目录但直接包含图片，入口本身会作为一篇笔记
- 重复的笔记文件夹按完整路径去重，只保留第一次出现的位置

按笔记上传只需要填写「表格起始行」。系统会根据有效笔记数自动计算写入范围：第一篇写入起始行，第二篇写入下一行，依次类推。

**第四步：开始上传**

点击「**开始一键上传**」，进度条实时显示当前进度。上传过程中可点击「**取消**」中止任务。

### 注意事项

- 上传会**追加**到原有附件后，不会覆盖已有附件
- 顺序模式下，图片按文件名排序循环选取（不同行之间循环复用）
- 随机模式下，同一行内不重复抽取；不同行之间可能选到相同图片
- 图片数量少于每行配置总数时会报错提示
- 按笔记上传不自动新增飞书表格行；如果有效笔记数超过当前表格记录数，会在上传前阻断
- 按笔记上传不会写入笔记标题字段，一期只追加附件图片

### 使用示例

**场景：** 为多维表格第 2–6 行每行写入 3 张图（2 张顺序 + 1 张随机）

1. 填入 PersonalBaseToken 和表格链接
2. 附件字段填写「商品图片」
3. 起始行 `2`，结束行 `6`
4. 添加文件夹 A（含 20 张图），选「顺序上传」，每行 2 张
5. 添加文件夹 B（含 15 张图），选「随机上传」，每行 1 张
6. 点击「开始一键上传」
7. 完成后，第 2–6 行每行新增 3 张附件图片

**场景：** 将一个批次文件夹内的笔记逐行上传

目录结构：

```text
D:\笔记批次
├─ 账号A
│  ├─ 1-穿搭
│  │  ├─ 01.png
│  │  └─ 02.png
│  └─ 2-家居
│     └─ 01.png
└─ 账号B
   └─ 1-美妆
      └─ 01.png
```

操作：

1. 填入 PersonalBaseToken、表格链接和附件字段
2. 起始行填写 `2`
3. 切换到「按笔记上传」
4. 点击「选择父文件夹」，选择 `D:\笔记批次`
5. 检查笔记列表和写入行号
6. 点击「开始一键上传」

结果：

```text
账号A / 1-穿搭 -> 第 2 行
账号A / 2-家居 -> 第 3 行
账号B / 1-美妆 -> 第 4 行
```

## 小红书商品下载

**用途：** 自动抓取小红书商品详情页的主图和详情图，批量下载保存到本地。

### 操作步骤

1. **输入商品链接**：在文本框中粘贴商品链接（每行一个，也支持空格、逗号、分号分隔）
   ```
   https://www.xiaohongshu.com/goods-detail/xxxxxxx
   https://www.xiaohongshu.com/goods-detail/yyyyyyy
   ```
2. **选择输出目录**：点击「**选择输出目录**」
3. **开始下载**：点击「**开始下载**」
4. 右侧内置浏览器自动加载商品页面并滚动提取图片
5. 点击「**停止**」可随时中止所有任务

### 任务状态说明

| 状态 | 说明 |
|-----|------|
| 待处理 | 等待处理 |
| 加载中 | 正在加载商品页面 |
| 提取中 | 正在提取图片链接 |
| 下载中 | 正在下载图片到本地 |
| 保存中 | 正在写入文件 |
| 完成 | 下载成功 |
| 失败 | 下载失败（悬停查看原因） |
| 已停止 | 用户手动停止 |

任务列表显示每个商品的**标题**、当前进度（成功/失败/跳过数量），以及最终状态。下载成功后会弹出通知，点击「打开文件夹」可直接查看结果。

### 输出规则

- 每个商品在输出目录中生成独立文件夹（以商品名命名）
- 图片文件命名为 `image_001.jpg`、`image_002.jpg` 等
- 系统自动跳过过小图片（小于 200×200 像素）、头像、Logo 等无关图片
- 图片下载后转换为 JPG 格式保存

### 注意事项

- 首次使用时，需要在右侧内置浏览器中**登录小红书账号**（登录状态持久保存，后续不需要重复登录）
- 若提取到的图片链接为空，请确认链接有效、页面可正常访问；必要时在内置浏览器中手动刷新页面后重新开始
- 商品已下架或无图时会标记为「失败」

## 常见问题与错误排查

**Q：Word / PPT 导出失败怎么办？**

A：当前版本默认使用 **内置 LibreOffice 运行时**。请按以下顺序排查：
- 点击弹窗「重新检测」，确认预检分数与错误提示
- 点击「复制诊断信息」并导出运行日志，定位 `runtime.source / errorCode`
- 若提示运行时缺失或损坏，优先重装 Full 安装包
- 如仍失败，可点击「下载 LibreOffice」安装系统版作为兜底
- WPS 不兼容，无法替代 LibreOffice

如 LibreOffice 正常但仍失败，可导出运行日志查看具体错误信息。也可先手动将文档导出为 PDF，再通过本软件的 PDF 导出功能转 PNG。

---

**Q：导出卡住很久没有进度怎么办？**

A：PPT 导出通过 LibreOffice 引擎处理，在大文件或系统负载高时可能变慢。软件内置了分层并发与自适应控制，会在检测到超时或进程异常时自动降速重试。若长时间无响应，可按顺序处理：
- 点击「取消」后重试，确认日志中是否出现错误码（如 `LO_TIMEOUT`）
- 降低任务压力：优先使用 `1x`、先导出前几页、减少单批文件数
- 大文件优先单独导出，不与大量小文件混跑
- 仍然异常时，导出运行日志并附上诊断信息给开发者排查

---

**Q：导出后找不到图片？**

A：检查输出目录路径是否正确。若勾选了「输出到子文件夹」，图片会在以**原文件名**命名的子文件夹内，而不是直接在输出目录根目录下。

---

**Q：拼图无法预览或生成？**

A：请确认：
- 已设置背景图，或勾选了「透明背景」/「纯色背景」（三者至少选一）
- 已导入图片素材
- 若为多文件夹模式，请先为各拼图页选择文件夹；未选文件夹的页面不参与生成

---

**Q：百变拼图导出提示「图片解码失败」或「Illegal byte sequence」怎么办？**

A：该错误表示某张图片解码失败，常见原因：文件损坏、文件名包含特殊字符、图片格式不兼容。
处理方法：查看日志中报错的阶段（如「图片元素处理」「背景解码」）和文件名，对对应图片执行「重新导出/另存为」或替换后重试。若仍失败，请导出日志并反馈具体文件名和阶段信息。

---

**Q：拼图时图片显示不全、裁剪位置不对？**

A：默认图片会「填充」坑位（可能裁剪边缘）。选中坑位，点击「**裁剪设置**」手动调整缩放比例和水平/垂直偏移，可精确控制图片显示区域。

---

**Q：飞书上传提示「授权码无效」？**

A：请确认：
- 使用的是 PersonalBaseToken（非 App Token）
- API 域名为 `base-api.feishu.cn`（不是普通飞书网页域名）
- 表格链接中包含 `table` 与 `view` 参数

---

**Q：飞书上传提示「字段不存在」？**

A：「飞书附件字段」名称必须与多维表格中的列名**完全一致**（包括空格、全半角），且该字段类型必须为「附件」类型。

---

**Q：小红书下载为空或失败？**

A：
1. 确认商品链接格式正确且商品未下架
2. 在右侧内置浏览器中检查是否已登录小红书账号
3. 若页面加载不完整，可在内置浏览器中手动刷新后重新开始下载
4. 部分商品可能存在反爬限制，可稍等片刻后重试

---

**Q：导出图片清晰度不够？**

A：在「清晰度倍率」中选择 `2x` 或 `3x`。倍率越高画质越好，但生成时间和文件体积也会相应增大。建议日常使用 `2x`。

---

**Q：如何排查未知错误？**

A：进入「**设置**」页 → 运行日志区域 → 点击「**导出日志**」，将 `run-log.txt` 文件发送给开发者，日志中包含详细的操作时间、错误类型和文件名信息。
